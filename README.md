# qa-forum-spring

Q&A-форум: вопросы, ответы, теги, голоса, роли, REST API · *Stack Overflow-style Q&A forum*

`Java 17` `Spring Boot` `Spring Security` `Thymeleaf` `PostgreSQL` `OpenAPI`

```bash
./mvnw spring-boot:run
```
БД `qa_db`, доступ через `DB_USER` и `DB_PASSWORD`. Сайт: http://localhost:6767
